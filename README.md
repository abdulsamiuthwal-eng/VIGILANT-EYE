# VIGILANT EYE 👁️
AI-powered real-time surveillance system using YOLOv8 and OpenCV for intelligent object detection, monitoring, and automated alert generation.
## ⚙️ Email Configuration (SMTP)
To enable email alerts, follow these steps:
1. Open `config.py`
2. Line 45 → Enter your Gmail address
3. Line 46 → Enter your Google App Password
### How to generate App Password:
- Go to Google Account → Manage Account
- Click Security
- Search "App Passwords"
- Create new app (e.g. Vigilant Eye)
- Copy the generated key → paste in Line 46

> ⚠️ Never share your App Password publicly.
